INTERACTIVE TOOL

1. Choose an equation

Select a sample equation. The tool finds a root where f(x) = 0.

Angles in the cosine example are measured in radians. For Bisection, choose an interval where f(a) and f(b) have opposite signs.

Equation preview

f(x) = x³ − x − 2

2. Bisection Method

Bisection repeatedly halves an interval that contains a sign change.

Run the method to see the approximate root and iteration history.

3. Newton–Raphson Method

Newton–Raphson uses the derivative to make a new estimate.

Choose an initial guess and run the method.

4. Error Comparison

The graph compares the absolute change between consecutive estimates for the most recent run of each method.

Run one or both methods to draw the error comparison.

5. Iteration table

Each row shows the estimates produced by the selected numerical method.

Run a method to generate its iteration table.

Assignment details

Chosen unit: Numerical Methods (Unit 2)

Objective: Build an interactive tool that approximates equation roots using Bisection and Newton–Raphson and compares their convergence.

Mathematical concepts: Root finding, interval halving, derivatives, iterative approximation, tolerance, and absolute error.

Application in computing: Numerical methods are used in engineering simulations, scientific computing, graphics, optimization, and calculations where exact symbolic solutions may be difficult.

What I learned: Bisection is reliable when the interval brackets a root, while Newton–Raphson can converge faster with a good initial guess but may fail if the derivative is zero or the guess is unsuitable.
